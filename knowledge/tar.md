```bash
tar -czvf archive.tar.gz mon_dossier/
```

- `-c` : create (créer une archive)
- `-z` : compresser avec gzip
- `-v` : verbose (affiche les fichiers traités)
- `-f` : indique le nom du fichier archive

```bash
tar -xzvf archive.tar.gz
```

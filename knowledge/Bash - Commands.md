# Terminal Commands

Voici quelques raccourcis clavier pratiques pour la ligne de commande sous Linux en utilisant le mode par defaut emacs :

### Déplacements du curseur

- **`Ctrl + A`** : Aller au début de la ligne.
- **`Ctrl + E`** : Aller à la fin de la ligne.
- **`Alt + F`** : Avancer d'un mot.
- **`Alt + B`** : Reculer d'un mot.
- **`Ctrl + F`** : Avancer d'un caractère.
- **`Ctrl + B`** : Reculer d'un caractère.

### Édition de texte

- **`Ctrl + U`** : Couper le texte entre le début de la ligne et le curseur.
- **`Ctrl + K`** : Couper le texte entre le curseur et la fin de la ligne.
- **`Ctrl + W`** : Couper le mot précédant le curseur.
- **`Alt + D`** : Couper le mot suivant le curseur.
- **`Ctrl + Y`** : Coller le texte coupé (yank).
- **`Alt + .`** : Insérer le dernier argument de la commande précédente.
- **`Alt + U`** : Mets en majuscule le mot suivant.
- **`Alt + L`** : Mets en minuscule le mot suivant.

### Manipulation de commandes

- **`Ctrl + L`** : Effacer l'écran (équivalent de la commande `clear`).
- **`Ctrl + C`** : Terminer un processus en cours.
- **`Ctrl + Z`** : Suspendre un processus en cours.
- **`Ctrl + R`** : Rechercher dans l'historique des commandes.
- **`!!`** : Exécuter la dernière commande.
- **`!n`** : Exécuter la commande numéro `n` dans l'historique.
- **`!command`** : Exécuter la dernière commande qui commence par `command`.

### Historique et rappel de commandes

- **`↑` (Flèche Haut)** : Revoir la commande précédente dans l'historique.
- **`↓` (Flèche Bas)** : Revoir la commande suivante dans l'historique.
- **`Ctrl + P`** : Aller à la commande précédente (comme la flèche haut).
- **`Ctrl + N`** : Aller à la commande suivante (comme la flèche bas).

Ces raccourcis devraient t'aider à être plus efficace sur la ligne de commande.

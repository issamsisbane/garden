https://super-productivity.com/

Un super outil pour gérer ses taches avec un timer pour compter le temps en plus.

Seul défaut de l'application c'est que seulement le front end est self-hostable.

Pas possible de host seulement le backend. Selon la doc et des issues github c'est possible de sync le contenu entre plusieurs appareils via [[WebDav]]
